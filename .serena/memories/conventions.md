# Conventions
- User communication is English unless explicitly asked otherwise. Audience-facing deliverables must exclude production/process/editorial notes unless requested; put that information in chat. Preserve citations and credits.
- kotlin.code.style=official in gradle.properties. Match nearby Kotlin formatting (four-space indentation); no repository-wide ktlint/detekt/formatter configuration is declared. Comments/KDoc include Chinese; avoid unrelated translation churn.
- Feature UI lives under ui/pages/<feature>/ with ViewModel and immutable *UiState data classes; feature-specific components stay within the feature, reusable ones in ui/components/.
- Repositories and ViewModels use constructor injection. Register dependencies in di/VerveDoDI.kt. Pages normally obtain ViewModels through koinViewModel and observe with collectAsStateWithLifecycle.
- State updates use MutableStateFlow.update + copy, combine repository/settings flows, stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), initialState), and viewModelScope.launch for writes.
- Reuse VerveDoDefaults, ui/theme, shared components and VibrationUtils. Preserve Material 3 Expressive styling and resource-backed accessibility/text rather than embedding new UI strings.
- English source strings are app/src/main/res/values/strings.xml; resources.properties declares en-US. Crowdin maps those keys into values-%android_code%/strings.xml and syncs through its GitHub workflow. Keep resource IDs and format placeholders compatible; locale configuration is generated by AGP.
- Enum persisted IDs/float values and preference keys are data contracts, not mere display ordering. Their definitions live in logic/model/ and constants/Constants.kt.
- Keep signing keys, local.properties, SDK/cache/build output and machine-specific Serena overrides out of version control. Avoid unrelated edits in a shared working tree.
